API

Everything on this site comes from these JSON endpoints. No key needed, CORS is open, and responses are cached for 60 seconds. {net} is mainnet or testnet. Amounts are in duffs (1 DASH = 100,000,000 duffs); times are unix seconds.

GET /api/v1/status

Our dashd's sync state, the crawler's state and the payment index range, per network.

GET /api/v1/{net}/summary

The latest finished crawl, the crawl about 24 hours before it, and every distribution from the latest crawl: dists[scope][dim] = [[key, count], …], largest first.

Scopes: all (every node that answered), nonmn (those that aren't masternodes), mn and evo (every enabled masternode or evonode, reachable or not, keyed by the user agent it last announced in the past 7 days, else Unknown).

Dimensions: ua, version, client, protocol, country (ISO 3166), asn, reachable, status and type (masternode scopes).

curl https://nodes.dashhq.org/api/v1/mainnet/summary | jq '.dists.mn.version'

GET /api/v1/{net}/history?scope=mn&dim=version&days=30&top=8

A time series of one distribution: {resolution, t: [...], series: [{key, values}]}. Up to 14 days back it has one point per crawl; past that, daily averages. Keys outside the top top (by total over the window) fold into Other. dim=totals returns reachable nodes, enabled masternodes and reachable masternodes instead.

GET /api/v1/{net}/masternodes

Every registered masternode with its latest port check (reachable is null when the latest crawl didn't check it), announced user agent, geolocation and 7- and 30-day port-check uptime.

GET /api/v1/{net}/masternodes/{protx}

One masternode: everything from the list plus collateral and keys, version history, 90 days of daily uptime and its 25 latest payments.

GET /api/v1/{net}/masternodes/{protx}/payments?before={height}&limit=100

Older payments, newest first. Page with before set to the last height you got.

How the data is collected

Every 15 minutes the crawler opens a P2P connection to every registered masternode's Core address, to every node that answered in the past week, and to new addresses learned from our dashd and from other nodes' getaddr replies. It completes the version handshake and disconnects. It announces itself as /dash-nodes:…(nodes.dashhq.org)/, doesn't relay transactions and keeps nothing but what the node announces. Masternode registration data and payments come from our own dashd. Reachability is measured from one vantage point, so a node that blocks or rate-limits us shows as unreachable even when others can reach it.

Non-masternode IP addresses are never published, only counted.
